# 통합 폴더 (integrated)

Idea 1–6의 최종 베이스라인을 한곳에 정리한 폴더다. 원본 아이디어 폴더는 수정하거나 이동하지 않았다.

| 파일 | 내용 |
|---|---|
| `Stochastic_PRIM_통합보고서.md` / `.docx` | 통합 보고서 (본문) |
| `baseline/00_baseline_summary.md` | 아이디어별 최종 베이스라인 한 장 요약 |
| `baseline/scripts_index.md` | 정본 스크립트와 이력 스크립트 색인 |
| `results/idea5_run_output.txt` | Idea5 재실행 결과 (기존에 보고서 없음) |
| `results/idea4_*.csv` | Idea4 연결성·통제 실험 요약 CSV 사본 |

Idea5는 이번에 `idea5/idea5_dro_concrete.py`를 실행해(14.7초) 결과를 얻었다. 그 외 수치는 기존 보고서에서 옮겼고 다시 실행하지 않았다.
